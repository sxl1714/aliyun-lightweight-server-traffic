## 超出套餐流量会停机吗？超额怎么收费

不会直接停机。配额用完后，阿里云按实际超额流量以按量付费方式收费，费用自动从账户可用额度（含账户余额和代金券）里扣，服务器照常运行。真正导致关停的是账户欠费——余额扣完又没充值，才会触发欠费停机。

超额流量单价如下：

- 中国内地：0.8元/GB
- 中国香港：1元/GB
- 新加坡：0.53元/GB

三条容易忽略的规则：

1. 流量统计的是出网流量，入网不计费。往服务器上传文件、拉取镜像，这些都不产生费用。
2. 每月1日自动重置固定流量配额，重置后重新开始计算已用流量。
3. 用量明细可以在订单详情里查，官方也提供账单和用量查询入口。

## “200M带宽不限流量”是真的吗

能短时冲到200Mbps，流量总量也没有上限，但它是无SLA保障的共享峰值带宽，长时间持续跑高会被限速——这是买过的人反馈比较一致的结论。

先把带宽和流量分开。带宽是速度上限，单位Mbps；流量是实际传输量，单位GB。“不限流量”说的是后者没有月度配额，而200M是“峰值公网带宽”：多个实例共享网络资源，突发流量可以跑满，持续占用则看运气。

V2EX上2025年9月有个讨论帖，买家反馈可以归成几条：下载安装包、网页访问这类突发请求没问题，峰值确实能到；但持续高带宽会被限速——有人拿它做游戏串流，长时间高占用后被限到不到1Mbps；有人实测跑多了平均只剩3-5Mbps；还有用户反映高峰期UDP丢包能到50%以上。也有顺手的例子，一位南京节点（现已停售）用户表示从没遇到限速，他的经验是选人少的可用区，因为这种机型是一个可用区共享一条1G带宽。社区里还有对比腾讯云200M轻量的声音，认为后者高峰期表现更稳，这类体验因节点和时段差异很大，只能当参考。

结论可以给得比较明确：博客、企业官网、小程序后端这类场景，一个月几十GB的量完全够用，不用盯流量表；要做持续大文件分发、长时间视频串流这类匀速大流量业务，就别按峰值规划预期。另外，不限流量也不等于可以滥用——异常流量或违反服务条款的用法，阿里云可以按规定处理。

## 常见问题

**流量统计出网还是入网？**

只统计出网流量，入网不计费。

**每月流量什么时候重置？**

每个自然月的第一天（1日）自动重置，重置后重新计算已用流量。

**不限流量的套餐会有流量费用吗？**

不会。没有固定流量配额的套餐不产生超额流量，也就没有对应的费用。
